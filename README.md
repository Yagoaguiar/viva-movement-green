# Viva Movement - verde e creme

## Visualizar
Abra index.html no navegador. Mantenha style.css e hero.png na mesma pasta. Nao requer instalacao nem compilacao.

- style.css: estilos
- hero.png: imagem ilustrativa gerada por IA
